# 探索页本地视觉模型

“探索”页仅使用本目录中的 SigLIP2 图像塔做本机特征提取。运行时不会上传头像或封面，
也不会创建同步、下载或上传任务。

正式启用时需要同时存在：

- `siglip2-int8.json`：可入库的模型清单，包含模型版本、结构参数、量化质量结论和 SHA-256。
- `siglip2-vision-int8.onnx`：约 101 MiB 的本地运行资产，因 GitHub 单文件限制保持 Git 忽略。

后端每个进程首次使用前都会完整计算 ONNX 文件 SHA-256；清单未通过质量门禁、文件缺失、
哈希不一致或 ONNX Runtime 推理失败时，探索页会显示明确的不可用状态，不会退回旧推荐器。

当前资产来自已下线推荐功能的可逆快照，清单声明版本
`siglip2-base-p16-224-int8-v1`，32 张本机样本的 INT8 平均余弦漂移为
`0.0009302`，低于清单门槛 `0.02`。
