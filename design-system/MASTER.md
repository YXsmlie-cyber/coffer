# PH-115 Sync — 设计系统

接近 Apple 官网的明亮界面，颜色跟随系统浅色/深色。先保证信息清楚、状态可信与操作稳定，再用颜色和层次表达重点；所有导航、命令顺序、禁用条件与确认步骤沿用业务组件。

## 权威来源与样式边界

颜色、圆角、间距、触控尺寸的权威来源为 `frontend/src/styles/tokens.css`，不在文档维护另一套色值副本。

`frontend/src/style.css` 固定按以下顺序导入：tokens → shell → controls → media → tasks-dialogs → responsive → library → taste → liked-models → media-library。拆分保留原有级联关系，不将页面访问顺序变成样式依赖。修改共享类前需检查所有使用页面，弹窗包含 Teleport 的大图。

## 层次与色彩

- 颜色跟随系统：浅色值写在 `tokens.css` 的 `:root`，深色值只在 `@media (prefers-color-scheme: dark)` 中覆盖；组件只引用令牌，不写死某一主题的颜色。不提供应用内主题开关。
- 浅色为浅灰页面（`--bg`）上放白色卡片（`--surface`），深色为黑底上放深灰卡片；边框是发丝细线，层次主要靠底色与柔和阴影。
- 导航与任务托盘使用半透明磨砂（`--nav-bg` / `--elevated` + backdrop-filter）；遮罩统一用 `--scrim`。
- 按钮为胶囊形：主按钮 Apple 蓝实心，次要按钮用中性填充 `--fill-1/2`，不加描边；分段控件为灰色轨道上的白色滑块。
- 主按钮使用独立的 `--button-bg / --button-hover / --button-text`，白字在普通与悬停态都至少达到 4.5:1。链接/数据蓝 `--accent-2` 与按钮背景分开调整。
- 状态文字色（`--accent-2 / --amber / --ok / --warn / --err / --violet`）在两种主题的页面与卡片底色上都至少 4.5:1，由 `button-contrast.test.mjs` 同时检查浅色和深色；`--*-fill` 只用于进度条、角标等图形填充。
- 叠在照片上的角标、翻页按钮、时长和大图背景固定为深色半透明配白字，不随主题变化。
- 危险实心确认按钮使用 `--danger-bg / --danger-hover` 配白字；普通删除动作使用浅红文字，不改变确认规则。
- 蓝表示当前/运行，琥珀表示缺失/待处理，绿表示成功，红表示错误，紫表示跳过。保留文字与徽章，不只靠颜色传达状态。
- 汇总统计以中性色数字为主，突出进行中与需要处理的异常；完成项不持续发光。
- 禁用态保留原有条件，降低视觉强度但仍可辨认。

## 字体与空间

- 使用系统字体栈（`--font-text` / `--font-display` / `--font-mono`，优先 SF Pro 与 Segoe UI Variable），不从外部字体服务发请求；数字用 tabular-nums，标识与速度沿用系统等宽字体。
- 页标题约 34–40 px、粗体、略收字距，正文 15 px，辅助文字不低于 12 px；紧凑卡片可调整空间，不能靠 9–10 px 字号塞入信息。
- 间距使用 4/8/12/16/24/32 px 令牌，卡片采用统一圆角和细边框。标题与主操作优先于装饰。
- 封面保持 16:9，明示加载失败；图片保留 lazy/async decoding/固有尺寸。来源链接、头像链接和查看大图分别保持原行为。
- 任务行固定 62 px，对应 `TaskTable.vue` 的 `ROW_H`；视频详情行固定 58 px，对应 `VideoList.vue`（弹窗与详情抽屉共用）。不得仅改 CSS 高度使虚拟窗口错位。
- 任务行按钮与手机交互目标至少 44×44 px；失败行两个动作需共同容纳，不重叠、不横向溢出。手机继续隐藏原有模特/进度列，不额外隐藏命令。
- 115 卡片统计区使用真正的 grid，桌面五列、窄屏三列；统计和按钮顺序保持。

## 媒体库（模特页）

- 模特页使用宽容器（路由 `meta.wide`，最大 1680 px）和“上图下文”的白色磁贴：16:9 封面在上，头像、名字与 115 已有数在下方卡片底色上；同步进度是封面底边的细条。名次在左上，状态角标在右上：同步中 > 未同步 > 缺 N > 待上传 N > 已齐。
- 整张卡是一个按钮，只打开详情抽屉。快捷“下载 N”仅在可悬停设备的右上角浮现并暂时替代状态角标，不放在卡片中部，避免点开详情时误加入队列；触屏设备只在抽屉里下载。
- 详情抽屉在桌面是距窗口 10 px 的圆角浮层，手机铺满；它是模态对话框：沿用 `useModalFocus` / `useEscClose`，不 Teleport，保证确认框与封面大图仍在其上层；上一位/下一位只在当前页内切换，关闭后焦点回到当前查看的卡片。
- 任务托盘在浏览页右下角汇总进行中、排队与失败数，展开后显示进行中下载的整体剩余时间；下载/上传页隐藏。托盘与标签页标题/图标共用 `useTaskPulse`，只在任务状态变化或重连时节流读取一次进行中快照，不做周期轮询。
- 标签页标题在有任务时显示 `↓下载数 · 速度`、`↑上传数`、`⚠ 失败数`，后台跑完显示 `✓ 队列已清空`；图标右上角状态点：运行绿、失败红。
- 下载/上传页的统计胶囊同时是筛选按钮（选中为浅蓝底，`aria-pressed`），默认“活动”视图；“暂停”胶囊只在有暂停任务时出现。运行行显示速度后的剩余时间，冷却行显示“约 N 分钟后复查”，具体时刻放在悬停说明。
- 失败与跳过行在标题下显示一句人话原因（`utils/failureReason.js`），状态 pill 外包 44px 透明按钮，点击弹出“建议 + 原始信息”，失败任务可在弹窗内直接重试。
- 刚完成的任务在统计条下方显示“✓ 已完成 · 标题”约 4 秒，“完成”数字轻弹一次；浏览页托盘同时闪现“✓ 完成 N”。默认视图清空时显示绿色对勾“队列已清空”和今天完成数、字节与最后完成时刻。

## 动效与可访问性

- 稳定状态不使用永久发光脉冲，保留运行中进度与必要的加载反馈；禁止额外增加轮询或动画驱动的业务请求。
- 尊重 prefers-reduced-motion；用 focus-visible 保留清晰键盘焦点。
- 模特卡封面在图片加载完成前保持透明、露出骨架底色，完成后 0.2 秒淡入；换图重新等待，缓存命中直接显示。
- 托盘展开后在“下载中”下方画最近 60 秒总下载速度的细折线（每 2 秒本地采样，不发请求），仅作趋势示意，速度文字仍在胶囊中。
- 审美探索页：不再有两两比较与进度卡；打开即显示结果，没有结果或结果过期时自动开始计算并显示进度卡。顶部只保留“仅本机计算 · 不会自动下载”徽标。结果区标题写“根据你 115 里的 N 位收藏 · 第 x / y 组”，右侧与底部各一个“换一批”（每组 24 位，本地翻页）。“推荐准不准”先用一句话说明历史评价检验（前 30% 符合率对比整体），有评价时再显示每批符合率柱状图，AUC 收进“检验细节”。结果卡用对方小头像 + “像你收藏的 X”说明理由，“符合 / 不符合”保留但为可选。
- 全局快捷键：`/` 聚焦当前页搜索框，`g` + `m/l/v/t/d/u` 切换页面，`?` 显示说明；输入框内、带修饰键或有弹窗时不响应（`utils/shortcuts.js`）。
- 弹窗使用共同焦点管理，仅打开期间监听 Tab，约束最上层弹窗并在关闭后恢复原焦点。大图首次聚焦关闭按钮，保留 Escape/方向键/遮罩关闭。
- Bark 未保存修改以草稿提示表达，保持原有显式“保存”操作，不自动写后端或发送测试。

## 验收

运行 `npm test` 验证二维码生命周期、弹窗焦点、Bark 显式保存等边界；运行 `npm run build:check` 检查构建与 JavaScript/CSS gzip 预算。触控、布局与操作等价性仍需浏览器验收。

覆盖 375/390/768/1024/1440 宽度、长标题与大数字、空态/加载/错误/失败双按钮/运行中上传、键盘 Tab/Escape、减弱动态效果、六个路由切换与列表滚动恢复。视觉验收不发送真实同步/下载/上传/删除命令，可使用中性数据与只读代理。
